# 🐤 hiyocord

**hiyocord** is a collection of Cloudflare Workers-based distributed microservices that connect various external services with Discord.
It is developed and maintained as an open-source project.


### Our Products

Here is our product list:

- [npm packages](https://github.com/orgs/hiyocord/packages)
- [hiyocord-nexus](https://github.com/hiyocord/hiyocord-nexus) – The routing core built on Cloudflare Workers
- [documents](https://github.com/hiyocord/docs.hiyocord.org)
